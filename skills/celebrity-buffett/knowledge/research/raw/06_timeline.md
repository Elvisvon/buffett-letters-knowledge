# Track 06 — Timeline（认知轨迹）

**维度**: Dim 6 Timeline — 思想如何随时间演化（变化 > 固定）
**来源权重**: 1–3（选股方法演进 + 年度索引 1956–2025）

## 七段演化（变化点 = 最有信息量的部分）

1. **1956–1969 合伙基金期（格雷厄姆式烟蒂）**
   - 1956 合伙协议（10.51 万美元起步，家人朋友）；1957 三类投资（普通低估/套利/控股）；1958 Commonwealth Trust 经典低估；1959–60 Sanborn Map 隐藏资产（股东积极主义）；1961 Dempster 控股改造；1962 开始积累伯克希尔；1963–64 美国运通色拉油丑闻逆向（**品牌特许权认知的种子**）；1966 迪士尼/整体收购 Hochschild Kohn；1969 因市场投机化清盘离场（"不玩不懂的游戏"）。
   - 变化：纯定量低估 → 早期品质投资萌芽。
2. **1970s 转型期（芒格/费雪影响）**
   - 1972 喜诗糖果（**转折点**：为经济商誉付溢价）；1973 华盛顿邮报；1976 GEICO 濒死买入；1977 布法罗晚报 + 选股四标准 + ROE 衡量；1978 系统阐述浮存金 + 芒格任副董事长；1979 通胀=资本税。
   - 变化：从"买烂企业等修复"到"以合理价格买好企业"。
3. **1980s 特许权时代（定性为主）**
   - 1983 NFM（B 夫人）+ 经济商誉/所有者收益/回购系统论述；1985 首府/ABC（35 亿最大投资）+ 关闭纺织；1986 所有者收益公式 + 阿吉特加入；1987 黑色星期一 + 市场先生；1988 可口可乐 + 套利四步法 + 六大收购标准；1989 错误清单 + 制度性强制力 + 吉列/USAir 优先股。
   - 变化：建立完整特许权框架；从美国扩展到全球品牌；集中投资成熟。
4. **1990s 护城河与能力圈（方法论成熟）**
   - 1990 透视收益 + 富国银行；1991 所罗门危机 + 特许权/普通企业区分；1992 价值与成长一体两面；1993 Dexter（最差交易）+ 能力圈；1994 大师级框架；1995 GEICO 全资；1996 B 股 + 所有者手册 15 条；1998 通用再保险 + 衍生品担忧 + 不碰科技股；1999 跑输标普 20.5pp（压力测试）。
   - 变化：方法论完全成熟；"永久持有"确立；在泡沫压力下坚守能力圈。
5. **2000s 危机逆向（优先股 + 全资收购）**
   - 2000 中美能源/USG；2001 9/11 赔付 22 亿；2002 衍生品"大规模杀伤性武器"警告 + Clayton；2005 卡特里娜后承保纪律；2008 高盛/GE 优先股 + 《纽约时报》"买入美国"；2009 BNSF 260 亿全押美国。
   - 变化：规模增大后从二级市场转向全资收购与优先股；从美国走向国际（中石油/ISCAR）。
6. **2010s 品质科技 + 超大市值**
   - 2011 IBM（后认错）+ 美银优先股；2013 亨氏 + "投资成功不在于智商而在于性情"；2015 精密铸件（370 亿最大收购）；2016 苹果（能力圈扩展到科技平台）；2017 税改辨析；2018 Abel/Jain 任命；2019 停用账面价值 + 西方石油。
   - 变化：重新定义能力圈（苹果=消费品）；回购成为资本配置手段。
7. **2020s 日本商社 + 能源 + 现金期权（Abel 时代）**
   - 2020 清仓航空（认错）+ 建仓日本五大商社；2021 美国顺风 + 批评 meme 股/SPAC；2022 Alleghany + 西方石油/雪佛龙 + 台积电短暂持有；2023 纪念芒格；2024 最后一封 CEO 信（3340 亿现金、减持苹果为税务/集中度）；2025 Abel 首封信（巴菲特留任董事长，六大价值观）。
   - 变化：现金从"拖累"变为战略武器；从巴菲特到 Abel 平稳过渡。

## 跨时段矛盾与转折（供 synthesis 三重门使用）

1. 烟蒂 → 品质（1969 清盘 → 1972 喜诗）——同一人，两个投资时代。
2. "永远持有" → 实际大量卖出（IBM/航空/台积电/苹果减持）——原则是"基本面叙事 + 机会成本"，不是教条。
3. "别人恐惧时贪婪" → 2008 行动 vs 2020 观望——执行差异 = 对基本面可预测性的判断差异。
4. "用现金收购" 原则 → Dexter 用股票支付（最差交易，1993）。
5. 分散 → 集中（1963"分散是对无知的保护" → 1988 起可口可乐式重仓）。
6. 账面价值衡量 → 2019 停用（计量体系随生意结构演化）。

## Contradictions
- 烟蒂法（1969 前）→ 品质投资（1972 喜诗后）：两个投资时代共存于同一认知史
- "我们最喜欢的持有期是永远" vs 实际卖出 IBM/航空/台积电、减持苹果
- "别人恐惧时贪婪"：2008 大规模行动 vs 2020 年 3 月几乎按兵不动
- 原则"用现金收购" vs Dexter 用股票支付（自认最差交易）
- "分散是对无知的保护"（1963）→ 可口可乐式集中重仓（1988 起）
- 以账面价值为主要指标（1965–2018）→ 2019 正式停用
